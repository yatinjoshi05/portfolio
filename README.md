## Technical Stack & Performance

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + Vanilla CSS Design System Tokens
- **Animations:** GSAP 3 (ScrollTrigger, Timelines) + Lenis Smooth Scroll
- **Typography:** Host Grotesk (Google Fonts)
- **Deployment Platform:** Vercel Production (`portfolio-yatin-portfolio1.vercel.app`)
- **Optimization:** Image WebP compression, lazy loading, and deterministic reduced-motion support

## Local Development

```bash
# Clone the repository
git clone https://github.com/yatinjoshi05/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
